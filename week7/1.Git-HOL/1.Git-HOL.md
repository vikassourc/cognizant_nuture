# Git Hands-On Lab (1.Git-HOL)

**Prerequisite:** To create a new repository, signup with GitLab and register your credentials. Login to GitLab and create a “GitDemo” project.

## Step 1: Git Configuration

**1. To check if Git client is installed properly: Open Git bash shell and execute**
```bash
git --version
```
*(If the output shows Git with its version information, that indicates that the Git Client installed properly.)*

**2. To configure user-level configuration of user ID and email ID execute**
```bash
git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
```

**3. To check if the configuration is properly set, execute the following command.**
```bash
git config --global --list
```

## Step 2: Integrate notepad++.exe to Git and make it a default editor

**1. To check if notepad++.exe executes from Git bash**
```bash
notepad++
```
*(If Git bash is not able to recognize the `notepad++` command, that implies `notepad++.exe` is not added to the environment path variable.)*

**To add the path of notepad++.exe to the environment variable:**
Go to Control Panel -> System -> Advanced System settings. Go to Advanced tab -> Environment variables -> Add the path of notepad++.exe to the path user variable by clicking on “Edit”.

**2. To configure Notepad++ as the default Git editor, execute:**
```bash
git config --global core.editor "'C:/Program Files/Notepad++/notepad++.exe' -multiInst -notabbar -nosession -noPlugin"
```
*(Note: Adjust the path to Notepad++ depending on where it is installed on your system if necessary, or just use `notepad++` if it is in your PATH.)*
