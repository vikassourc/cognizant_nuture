# Git Hands-On Lab (2.Git-HOL)

**Objective:** Create a “.log” file and a log folder in the working directory of Git. Update the `.gitignore` file in such a way that on committing, these files (.log extensions and log folders) are ignored. Verify if the git status reflects the same.

## Step 1: Create the files and folder
```bash
# Create a .log file in the working directory
touch dummy.log

# Create a log folder and a file inside it
mkdir log
touch log/dummy2.log
```

## Step 2: Update `.gitignore`
We append `*.log` and `log/` to the `.gitignore` file so that git ignores them:
```bash
echo "*.log" >> .gitignore
echo "log/" >> .gitignore
```

## Step 3: Verify with `git status`
```bash
git status
```
**Expected Output:**
Git will show that `.gitignore` has been modified, but it will **not** show `dummy.log` or the `log/` folder as untracked files, because they are successfully being ignored by the `.gitignore` configuration.
