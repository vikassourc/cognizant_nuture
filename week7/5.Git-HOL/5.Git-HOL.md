# Git Hands-On Lab (5.Git-HOL)

**1. Verify if master is in clean state.**
```bash
git status
```

**2. List out all the available branches.**
```bash
git branch -a
```

**3. Pull the remote git repository to the master**
```bash
git pull origin main
```
*(Note: If the default branch is named `master`, use `git pull origin master`)*

**4. Push the changes, which are pending from “Git-T03-HOL_002” to the remote repository.**
```bash
git push origin main
```

**5. Observe if the changes are reflected in the remote repository.**
```bash
# You can verify remote tracking using git log:
git log --remotes --oneline
```
*(Alternatively, you can visit the repository on GitHub in your web browser to visually confirm that the changes are there.)*
